# 🎓 Edmey – Full Stack Learning Management System

Edmey is a modern Learning Management System (LMS) built to provide a seamless online learning experience for both students and instructors. The platform allows users to explore courses, enroll, learn through structured content, and manage their learning journey through an intuitive interface.

## ✨ Features

### 👨‍🎓 Student

* User authentication
* Browse available courses
* View course details
* Enroll in courses
* Watch course lectures
* Track learning progress
* Responsive user interface

### 👨‍🏫 Instructor

* Create new courses
* Upload course content
* Edit and manage courses
* Organize lessons and chapters
* Monitor enrolled students

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Rohit0265/Edmey-Full-Stack-LMS-Platform.git
cd Edmey-Full-Stack-LMS-Platform
```

### Install dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd server
npm install
```

### Configure Environment Variables

Create a `.env` file in both the frontend and backend directories and configure the required environment variables.

Example:

```env
MONGODB_URI=
CLERK_SECRET_KEY=
CLERK_PUBLISHABLE_KEY=
STRIPE_SECRET_KEY=
JWT_SECRET=
```

### Run the application

Backend

```bash
npm run dev
```

Frontend

```bash
npm run dev
```
